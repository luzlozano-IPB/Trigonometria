Trigonometria

1. Unitats angulars

El radian o radiant és una unitat del Sistema Internacional d'Unitats (SI), definida com l'angle amb un arc de circumferència de longitud igual al radi r d'aquesta.

El º, grau sexagesimal o degree, és 1 360 d'un angle complet.


Angle complet = 360º = 2π rad ; Angle pla = 180º = π rad

2. Raons trigonomètriques d’un angle

Una raó és una proporció entre dos valors.
Definim les següents raons: sinus (sin), cosinus (cos) i tangent (tg o tan).

3. Fórmules fonamentals

Aquestes fórmules les pots demostrar amb el teorema de Pitàgores i la definició de les raons al triangle rectangle.

A partir de la definició de les raons puc demanar:

  1. Donat un angle situar aquest en un quadrant o un eix → Representar gràficament les seves raons.
  2. Donat una raó d’un angle → Determinar els angles que tenen aquest raó

    (un amb la calculadora i un altre canviant de quadrant gràficament)

  3. Donat una raó d’un angle i el signe d’un altra o el quadrant → Determinar l’angle.

    (potser només amb la calculadora o canviant de quadrant gràficament)

  4. Relacionar les raons d’un angle qualsevol amb un del primer quadrant.
  5. Donat una raó trigonomètrica i el quadrant → Calcular la resta de raons utilitzant les fórmules fonamentals de la trigonometria.
    tan α =
    sin α cos α
    ;
    sin2 α + cos2 α = 1

4. Determinació de triangles

Un triangle està determinat si amb les dades que em donen es pot construir de manera única.

Si no està determinat pot ser que no es pugui construir o que hi hagi més d’una solució.

Per determinar un triangle necessitem coneixer:

  1. a) Els tres costats.

  2. b) Dos costats i l’angle que formen.

  3. c) Dos costats i l’angle oposat a un d’aquests costats.

  4. d) Un costat i dos angles.

  4. d) Sinus de la resta.

    sin(α−β) = sin(α)·cos(β) − cos(α)·sin(β)

  5. e) Sinus i cosinus de l'angle doble.

    cos(2α) = cos2(α) − sin2(α)
