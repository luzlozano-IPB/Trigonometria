Rectes al pla

1. Determinada per:

Una recta a l'espai bidimensional queda definida de manera única mitjançant un punt i una direcció.

  • Punt:
    • A(a₁, a₂)
  • Direcció:
    • Altre punt: B(b₁, b₂)
    • Vector director: v → = ( v1 , v2 ) → v → = AB → = (1,m)

    • Pendent (s'utilitza a les equacions explícita i punt/pendent) : m = tg (α) = v1 v2

    • Angle (α) que forma amb la direcció horitzontal
    • Representació gràfica

2. Expressada per una equació

  • Vectorial:

    (x,y) = (a1,a2) + k (v1,v2)

  • Paramètriques:

    { x=a1+k·v1 y=a2+k·v2

  • Contínua:

    x - a1 v1 = y - a2 v2

  • General / Implícita:

    Ax + By + C = 0 | v→ = ( -B , A ) | m = - A B

  • Explícita:

    y = m · x + n

  • Punt/Pendent:

    y - a2 = m · ( x - a1 )

  • Canònica:

    x p + y q = 1 | punts de tall amb els eixos P = ( p , 0 ) , Q = ( 0 , q )

Un punt pertany a una recta

Un punt P(x₀, y₀) pertany a una recta si al substituir les seves coordenades a l'equació de la recta, la igualtat és certa.

Informació sobre la recta

A partir d'un punt i la direcció podem escriure una equació de la recta i d'una equació podem passar a qualsevol altra.

A partir d'una equació podem trovar punts, vector director, pendent, angle amb OX+ i punts de tall amb els eixos.

3. Projecció ortogonal i Simètric

  • A' : Projecció ortogonal d'un punt A sobre una recta r: Intersecció de la recta donada amb una recta ortogonal que passi pel punt A (obtenint el punt A').

    { r : Ax + By + C = 0 s ⊥ r , A ( a1 , a2 ) ∈ s ⇒ s : B ( x - a1 ) - A ( y - a2 ) = 0

  • A'': Simètric d'un punt A respecte una recta r: Punt A'' que verifica:

    A A′ → = A′ A′′ → ⇒ A′′ = A + A A′ →

4. Posició recta r -punt A

  • El punt pertany a la recta

    • Al substituir el punt, es verifica l'equació de la recta.
    • La distància és 0.

  • El punt no pertany a la recta

    • Al substituir el punt, no es verifica l'equació de la recta (igualtat falsa).
    • La distància és igual a la distància entre el punt i la seva projecció ortogonal sobre la recta. També es pot calcular utilitzant la fòrmula següent:

    dist ( A , r ) = dist ( A( x0 , y0 ) , r : Ax + By + C = 0 ) = | A·x0 + B·y0 + C | A2 + B2

5. Posició relativa de dues rectes

  • Coincidents

    • Comprovar que tenen la mateixa direcció i un punt en comú.
    • El sistema format per les dues rectes té infinites solucions (0 = 0).
    • La intersecció és tota la recta.
    • L'angle que formen és 0°.
    • La distància és 0.

  • Paral·leles

    • Comprovar que tenen la mateixa direcció i un punt d'una recta no pertany a l'altra.
    • El sistema format per les dues rectes no té solució (0 = S).
    • No hi ha intersecció.
    • L'angle que formen és 0°.
    • La distància és igual a: dist(Punt d'una recta, altra recta).

    Distància entre dues rectes paral·leles r i s:

    r : ax + by + c = 0 | Ps = ( x0 , y0 ) ⇒ dist ( r , s ) = dist ( Ps , r ) = | A·x0 + B·y0 + C | A2 + B2

  • Incidentens o secants (es tallen)

    • Les dues rectes no tenen la mateixa direcció.
    • El sistema format per les dues rectes té solució única (x = a, y = b).
    • La intersecció és un punt (solució del sistema).
    • L'angle que formen es calcula amb el producte escalar dels seus vectors directors.
    • La distància és 0.

6. Inequacions (equacions de semiplans)

    Per resoldre una inequació de primer grau amb dues incògnites, ho hem de fer gràficament .

    • ax + by < c
    • ax + by ≤ c
    • ax + by > c
    • ax + by ≥ c

    En qualsevol dels casos anteriors hem de començar representant la recta: ax + by = c

    Pasos

    1. Representar la recta (ax + by = c):
      Es fa una taula de valors amb dos punts (preferiblement els punts de tall amb els eixos).
      Nota: Si la recta és horitzontal (y = c) o vertical (x = c), no cal fer taula i es pot dibuixar directament.
    2. Determinar el semiplà solució:
      S'agafa un punt d'un dels semiplans per veure si verifica la inequació i es marca com a resposta aquest semiplà o l'altre, incloent o no la recta segons si la desigualtat és estricta (<, >) o no (≤, ≥).
